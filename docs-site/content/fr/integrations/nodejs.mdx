# Bindings Node.js

LadderMD fournit des bindings Node.js via [napi-rs](https://napi.rs/).

## Installation

```bash
cd crates/laddermd-node
npm install
npx napi build --release --target aarch64-apple-darwin
```

## API

### `convertXml(xml: string): string`

Convertit du PLCopen XML en Markdown.

```javascript
const { convertXml } = require('./laddermd.node')
const md = convertXml(fs.readFileSync('circuit.xml', 'utf8'))
```

### `convertMnemonic(mnemonic: string): string`

Convertit du mnemonique Mitsubishi en Markdown.

```javascript
const { convertMnemonic } = require('./laddermd.node')
const md = convertMnemonic('LD X001\nAND X002\nOUT Y001\nEND')
```

### `mnemonicToXml(mnemonic: string): string`

Convertit du mnemonique en PLCopen XML.

### `xmlToMnemonic(xml: string): string`

Convertit du PLCopen XML en mnemonique.

### `validate(xml: string): ValidationResult`

Valide la conversion aller-retour.

```javascript
const { validate } = require('./laddermd.node')
const result = validate(xmlString)
// { parseOk: true, roundtripOk: true, totalRungs: 2,
//   contacts: 4, coils: 2, blocks: 0, errors: [] }
```
