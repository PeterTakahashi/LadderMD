# 対応回路

## 基本回路

| 回路 | 説明 | テストファイル |
|------|------|----------------|
| 自己保持回路 | シールイン接点 + リセット | `self_hold.xml` |
| インターロック回路 | b接点による相互排他 | `interlock.xml` |
| タイマー回路 | TONオンディレイタイマー | `timer.xml` |
| 非常停止回路 | b接点の非常停止 + 自己保持 | `emergency_stop.xml` |

## カウンターブロック

| ブロック | 説明 |
|----------|------|
| CTU | カウントアップ -- 立ち上がりでインクリメント、CV≥PVでQ=ON |
| CTD | カウントダウン -- 立ち上がりでデクリメント、CV≤0でQ=ON |

## 比較・演算ブロック

| ブロック | 説明 |
|----------|------|
| GT, GE, EQ, LE, LT, NE | 比較演算子 |
| ADD, SUB, MUL, DIV, MOD | 算術演算子 |

## 自己保持回路の例

```
|--[X001]--[X002]--+--(Y001)|
|                  |        |
|--[Y001]---------+        |
|                           |
|--[X003]-----------(R Y001)|
```

ロジック: `Y001 = (X001 AND X002) OR Y001`、X003でリセット。

最も基本的なPLCパターンです。起動ボタン(X001)を安全確認(X002)と共に押すとY001がラッチON。自己保持接点により停止ボタン(X003)でリセットするまで保持されます。
