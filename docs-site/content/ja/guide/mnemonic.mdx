# 三菱ニモニック形式

LadderMDは三菱MELSECのニモニック（命令リスト）形式に対応しています。GX Works / GX Developerで使用されるフォーマットです。

## 命令セット

### 接点命令

| 命令 | 意味 |
|------|------|
| `LD` | ロード -- 新規ラング開始、a接点 |
| `LDI` | ロードインバース -- 新規ラング開始、b接点 |
| `AND` | 直列AND、a接点 |
| `ANI` | 直列AND、b接点 |
| `OR` | 並列OR、a接点 |
| `ORI` | 並列OR、b接点 |

### 出力命令

| 命令 | 意味 |
|------|------|
| `OUT` | 出力コイル |
| `SET` | セット（ラッチ）コイル |
| `RST` | リセットコイル |
| `OUT T_ K_` | タイマー出力 |
| `OUT C_ K_` | カウンター出力 |

### ブロック接続

| 命令 | 意味 |
|------|------|
| `ORB` | ORブロック -- 並列パス結合 |
| `ANB` | ANDブロック -- 直列ブロック結合 |

### スタック（分岐）

| 命令 | 意味 |
|------|------|
| `MPS` | 現在の結果をスタックにプッシュ |
| `MRD` | スタックトップを読み取り |
| `MPP` | スタックトップをポップ |

## 例: 自己保持回路

```
LD  X001
AND X002
OR  Y001
OUT Y001
LD  X003
RST Y001
END
```
