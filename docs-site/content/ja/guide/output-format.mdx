# 出力フォーマット（LadderMD）

各ラング（横棒1段）は3つのセクションで構成されます。

## 1. 論理式

```
LOGIC: Y001 = (X001 AND X002 OR Y001)
```

## 2. デバイステーブル

```
| Device | Type        | LocalId |
|--------|-------------|---------|
| X001   | Contact(NO) | 2       |
| X002   | Contact(NO) | 3       |
| Y001   | Coil        | 5       |
```

## 3. ASCIIラダー図

```
|--[X001]--[X002]--+--(Y001)|
|--[Y001]--+        |
```

## シンボル一覧

| シンボル | 意味 |
|----------|------|
| `[X001]` | a接点（常開接点 / NO） |
| `[/X001]` | b接点（常閉接点 / NC） |
| `(Y001)` | 出力コイル |
| `(S Y001)` | セット（ラッチ）コイル |
| `(R Y001)` | リセット（アンラッチ）コイル |
| `[TON T1]` | ファンクションブロック（タイマー等） |
| `--+--` | 並列分岐の合流点（OR） |
