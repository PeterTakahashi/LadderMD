# 支持的电路

## 基本电路

| 电路 | 说明 | 测试文件 |
|---------|-------------|--------------|
| 自保持 | 带自保持触点和复位的锁存电路 | `self_hold.xml` |
| 互锁 | 通过常闭触点实现互斥 | `interlock.xml` |
| 定时器 | TON 接通延时定时器功能块 | `timer.xml` |
| 紧急停止 | 常闭紧急停止 + 自保持 | `emergency_stop.xml` |

## 计数器功能块

| 功能块 | 说明 |
|-------|-------------|
| CTU | 加计数——上升沿递增，当 CV≥PV 时 Q=ON |
| CTD | 减计数——上升沿递减，当 CV≤0 时 Q=ON |

## 比较与算术功能块

| 功能块 | 说明 |
|-------|-------------|
| GT, GE, EQ, LE, LT, NE | 比较运算符 |
| ADD, SUB, MUL, DIV, MOD | 算术运算符 |

## 自保持电路示例

```
|--[X001]--[X002]--+--(Y001)|
|                  |        |
|--[Y001]---------+        |
|                           |
|--[X003]-----------(R Y001)|
```

逻辑：`Y001 = (X001 AND X002) OR Y001`，由 X003 复位。

这是最基本的 PLC 模式。在确认安全信号（X002）的情况下按下启动按钮（X001），锁存 Y001 为 ON。通过自保持触点保持 ON 状态，直到停止按钮（X003）将其复位。

## 紧急停止电路示例

```
|--[/X010]--[X001]--+--(Y001)|
|                   |        |
|---[Y001]---------+        |
```

逻辑：`Y001 = NOT X010 AND (X001 OR Y001)`

使用常闭（NC）触点作为紧急停止。如果导线断开，触点断开——系统进入安全状态。
