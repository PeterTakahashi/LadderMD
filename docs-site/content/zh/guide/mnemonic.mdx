# 三菱助记符格式

LadderMD 支持三菱 MELSEC 助记符（指令列表）格式，适用于 GX Works / GX Developer。

## 指令集

### 触点指令

| 指令 | 含义 |
|-------------|---------|
| `LD` | 加载——开始新梯级，常开触点 |
| `LDI` | 加载取反——开始新梯级，常闭触点 |
| `AND` | 串联 AND，常开触点 |
| `ANI` | 串联 AND，常闭触点 |
| `OR` | 并联 OR，常开触点 |
| `ORI` | 并联 OR，常闭触点 |

### 输出指令

| 指令 | 含义 |
|-------------|---------|
| `OUT` | 输出线圈 |
| `SET` | 置位（锁存）线圈 |
| `RST` | 复位线圈 |
| `OUT T_ K_` | 定时器输出（如 `OUT T0 K100`） |
| `OUT C_ K_` | 计数器输出（如 `OUT C0 K10`） |

### 块连接

| 指令 | 含义 |
|-------------|---------|
| `ORB` | OR 块——合并并联路径 |
| `ANB` | AND 块——合并串联块 |

### 堆栈（分支）

| 指令 | 含义 |
|-------------|---------|
| `MPS` | 将当前结果压入堆栈 |
| `MRD` | 读取（查看）堆栈顶部 |
| `MPP` | 弹出堆栈顶部 |

### 程序控制

| 指令 | 含义 |
|-------------|---------|
| `END` | 程序结束 |

## 示例

### 自保持

```
LD  X001
AND X002
OR  Y001
OUT Y001
LD  X003
RST Y001
END
```

### 互锁

```
LD  X001
ANI X002
OUT Y001
LD  X002
ANI X001
OUT Y002
END
```

### ORB（并联块）

```
LD  X001
AND X002
LD  X003
AND X004
ORB
OUT Y001
END
```

### 定时器 + 计数器

```
LD  X001
OUT T0 K100
LD  T0
OUT Y001
LD  X002
OUT C0 K10
END
```
