# 输出格式（LadderMD）

每个梯级（rung）通过三个部分进行渲染：

## 1. 逻辑表达式

描述梯级的布尔公式：

```
LOGIC: Y001 = (X001 AND X002 OR Y001)
```

## 2. 设备表

梯级中所有的触点、线圈和功能块：

```
| Device | Type        | LocalId |
|--------|-------------|---------|
| X001   | Contact(NO) | 2       |
| X002   | Contact(NO) | 3       |
| Y001   | Coil        | 5       |
```

## 3. ASCII 梯形图

电路的可视化表示：

```
|--[X001]--[X002]--+--(Y001)|
|--[Y001]--+        |
```

## 符号参考

| 符号 | 含义 |
|--------|---------|
| `[X001]` | 常开触点（NO / a 触点） |
| `[/X001]` | 常闭触点（NC / b 触点） |
| `(Y001)` | 输出线圈 |
| `(S Y001)` | 置位（锁存）线圈 |
| `(R Y001)` | 复位（解锁）线圈 |
| `[TON T1]` | 功能块（如定时器） |
| `--+--` | 并联分支汇合点（OR） |
